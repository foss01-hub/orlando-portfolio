# Orlando Jordán Núñez - Portafolio técnico

Portafolio técnico de Orlando Jordán Núñez, estudiante de Ingeniería en Mecatrónica en la Universidad Latina de Panamá.

El sitio presenta un perfil de estudiante de Ingeniería Mecatrónica con enfoque en automatización, software, electrónica y proyectos técnicos.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Contenido estático

## Instalación

```bash
pnpm install
```

## Desarrollo

```bash
pnpm run dev
```

Abrir `http://localhost:3000`.

## Validación

```bash
pnpm run typecheck
pnpm run lint
pnpm run build
```

Los scripts equivalentes también existen para entornos que ejecuten comandos con `npm run`:

```bash
npm run dev
npm run build
npm start
```

## Assets requeridos

Estos archivos deben existir en `public/`:

- `public/orlando-jordan.jpg`
- `public/Orlando_Jordan_Professional_Portfolio_EN.pdf`

## Railway

Configuración recomendada:

- Build command: `pnpm run build`
- Start command: `pnpm start`
- Variables de entorno requeridas: ninguna

Railway debe detectar Node.js/Next.js automáticamente desde `package.json` y `pnpm-lock.yaml`.

## Checklist de contenido

- No se incluyen métricas, certificaciones, experiencia o tecnologías inventadas.
- No se muestra teléfono.
- No se muestra GitHub.
- No hay formulario de contacto.
- Los enlaces activos son correo, LinkedIn y descarga de CV.
- Los proyectos de IA/software se presentan como evidencia de resolución de problemas, automatización, documentación y aprendizaje técnico.
